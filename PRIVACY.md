# Privacy Policy — Deepfall Drill

Last updated: 15 November 2026

Deepfall Drill does **not** collect personal data or send game data to a game
server.

- The game has **no internet permission**. It works fully offline.
- Game progress (ore, upgrades, best depth, settings, checkpoint) is stored **only
  on the device**, in Android's private app storage.
- If you tap **Share**, the game passes a text summary containing your run depth,
  generated seed code and a death line to Android's system share sheet. You choose
  whether to send it and which app receives it; Deepfall Drill does not receive
  the shared text back.
- There are **no ads, analytics, crash-reporting or third-party SDKs**.
- The **VIBRATE** permission is used only for gameplay feedback (haptics), and it
  can be disabled in Settings.
- Uninstalling the game deletes its local progress.

The game has no account or game server. Shared run text is generated on demand;
the destination app handles it under its own privacy policy.
