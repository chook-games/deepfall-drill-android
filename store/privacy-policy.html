Privacy Policy — Deepfall Drill

Last updated: 15 November 2026

Deepfall Drill does not collect personal data or send game data to a game server.

What the app stores

  • Game progress (ore, upgrades, best depth, settings, checkpoint) is stored only on the device, in Android's private app storage.
  • If you tap Share, the game passes a text summary containing your run depth, generated seed code and a death line to Android's system share sheet. You choose whether to send it and which app receives it. Deepfall Drill does not receive the shared text back.
  • Uninstalling the game deletes that local progress.

What the app does not do

  • The game has no internet permission or game server. A destination app selected from the share sheet may use its own network connection.
  • No ads, analytics, crash-reporting or third-party SDKs.
  • No account, login, location, contacts, camera, microphone or files access.
  • The VIBRATE permission is used only for gameplay feedback and can be disabled in Settings.

Children

The game does not collect personal data from anyone, including children.
